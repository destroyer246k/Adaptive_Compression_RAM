# Simulation

This directory contains Verilog testbenches used to verify the Adaptive Compression-Aware Memory Controller.

The testbenches validate individual compression and decompression modules, adaptive mode selection, data packing, RAM operations, and write-path integration.

**Tools:** Xilinx Vivado 2025.1 and XSim Simulator.

Each testbench can be run independently by selecting the corresponding testbench module as the simulation top. Test results are checked against expected outputs to verify functional correctness.
