# RTL

This directory contains the Verilog RTL source files for the Adaptive Compression-Aware Memory Controller, including the RLE and delta compression modules, adaptive selector, data packers, output formatter, write controller, and memory modules.

The RTL is designed for the Xilinx Spartan-7 `XC7S15FTGB196-1` FPGA using Vivado 2025.1.
